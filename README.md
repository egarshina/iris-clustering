# iris-clustering
Кластеризация датасета Iris методами ML

Проект по кластеризации датасета Iris с использованием нескольких алгоритмов машинного обучения без учителя.

## Описание

Проект демонстрирует применение методов кластеризации к датасету Iris. Проведён исследовательский анализ данных, применён KMeans. Сравнили его с другими алгоритмами, оценили качество кластеризации.

## Структура репозитория

`01_EDA.ipynb` — загрузка данных, визуализация, boxplot по видам, pairplot, корреляционная матрица.
`02_KMeans_Clustering.ipynb` — стандартизация, определение оптимального числа кластеров (локтевой метод и метод силуэта), обучение KMeans, визуализация через PCA, оценка ARI и силуэта.
`03_Algorithm_Comparison.ipynb` — сравнение KMeans, иерархической кластеризации, DBSCAN и GMM.

## Используемые технологии

- Python 3
- NumPy, Pandas
- Matplotlib, Seaborn
- Scikit-learn

## Как запустить

1. Клонировать репозиторий.
2. Открыть нужный ноутбук в Jupyter Notebook или Google Colab.

## Результаты

- Оптимальное число кластеров по локтевому методу и силуэту — 3, что совпадает с реальным числом видов ириса.
- KMeans даёт Adjusted Rand Index (ARI) ≈ 0.73 и силуэт ≈ 0.50.
- Иерархическая кластеризация и Gaussian Mixture Models показывают сопоставимые результаты.
- DBSCAN хуже подходит для этого датасета, так как кластеры сферические и без выбросов.

## Выводы

Датасет Iris хорошо подходит для кластеризации благодаря чёткому разделению видов. Алгоритмы, предполагающие сферические кластеры (KMeans, GMM), сработали лучше, чем плотностные методы (DBSCAN).
